# Coração Sereno

Crie um site completo, original e profissional em português do Brasil para o cardiologista Dr. Marco Aurélio Santos Cordeiro. O projeto deve ser funcional, responsivo e pronto para revisão, com todas as páginas e rotas implementadas. Não publique ainda.

OBJETIVO CENTRAL
Atrair pacientes para teleconsultas cardiológicas em todo o Brasil, transmitindo autoridade científica, serenidade, escuta e humanidade. A conversão principal é iniciar uma conversa administrativa com a secretária no WhatsApp. A experiência precisa ser extremamente simples para pessoas idosas ou com pouca familiaridade digital.

IDENTIDADE E DIREÇÃO VISUAL
- Crie uma identidade original, sóbria, humana e contemporânea.
- Paleta sugerida: azul-marinho profundo, marfim quente, cinza azulado e pequeno acento terracota/coral escuro. Evite o visual hospitalar genérico e excesso de vermelho.
- Use tipografia de alta legibilidade, tamanhos confortáveis, excelente contraste e áreas clicáveis grandes.
- Visual editorial com bastante respiro, detalhes lineares inspirados em ritmo e circulação, sem clichês de coração anatômico.
- Não use foto inventada, avatar, retrato de banco de imagens fingindo ser o médico, depoimentos, estrelas ou estatísticas inventadas. No hero, use composição abstrata elegante em CSS/SVG, com linhas de ritmo e formas orgânicas discretas.
- Ícones simples e reconhecíveis. Animações suaves e respeitar prefers-reduced-motion.
- Mobile-first. Botão fixo de WhatsApp discreto no desktop e barra fixa clara no mobile, sem cobrir conteúdo.

SEO E PRESENÇA OFICIAL
- Títulos e descrições únicos por rota, canonical apropriado quando domínio existir, sem inventar domínio.
- HTML semântico, um H1 por página, headings lógicos.
- Open Graph básico.
- JSON-LD Schema.org para Physician/Person de forma prudente usando apenas os dados fornecidos; não inventar endereço, avaliações, preço, e-mail, foto ou redes sociais.
- Conteúdo textual indexável, URLs amigáveis, sitemap/robots quando aplicável.
- Nome completo e CRM/RQE em locais consistentes.
- Preparar estrutura para futura publicação de artigos.

ACESSIBILIDADE E UX
- WCAG AA, foco visível, navegação por teclado, skip link.
- Texto base mínimo confortável e opção simples A-/A+ no cabeçalho para aumentar fonte, persistindo localmente.
- Botões com linguagem explícita, não apenas “saiba mais”.
- Menu mobile simples, breadcrumb nas páginas internas.
- Não esconder informação essencial em hover.
- Número de telefone legível em formato brasileiro.
- Evitar carrossel.
- Validar que todos os links e CTAs funcionam.

ÉTICA
Não prometer resultados, cura ou melhora. Não usar superlativos subjetivos, comparações, depoimentos, avaliações, números inventados ou selos falsos. Não alegar atendimento presencial. Não criar diagnóstico pelo site. Não solicitar dados de saúde.
